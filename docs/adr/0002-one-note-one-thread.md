# ADR 0002: 一笔记一线程（One Note, One Thread）

- **状态**: 已接受
- **日期**: 2026-07-14

## 背景

需要决定如何将 Codex thread 与 Obsidian 笔记关联。

## 方案

**每个 Markdown 笔记对应一个独立的 Codex thread。**

- 用户打开笔记时，自动创建或恢复对应的 thread
- 切换笔记时，自动切换 thread（当前 thread 归档，新笔记的 thread 恢复）
- Thread 名称设为 `🤖 笔记相对路径`，方便在 Codex 桌面上查找
- 使用 `ThreadRegistry` 维护 `笔记路径 → thread ID` 映射，持久化到 `data.json`
- 关闭笔记时可选归档 thread

## 备选方案

- **全局单会话**：所有笔记共享一个对话。适合跨笔记的连续工作流，但切换笔记时上下文混乱
- **手动绑定**：用户手动选择 thread。灵活但操作成本高

## 后果

- 每个笔记的对话历史独立，互不干扰
- 切换笔记时 AI 自动切换上下文，体验流畅
- 打开大量笔记时会创建大量 thread，需要 thread 管理器来清理
- 无法跨笔记的连续对话（用户需要手动复制粘贴或@引用）
