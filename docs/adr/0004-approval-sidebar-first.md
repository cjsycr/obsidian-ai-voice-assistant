# ADR 0004: 审批——侧边栏内嵌优先，Modal 兜底

- **状态**: 已接受
- **日期**: 2026-07-15

## 背景

Codex 在操作文件时会发送审批请求（exec 命令、patch 文件修改）。需要决定审批 UI 的呈现方式。

## 方案

**优先在侧边栏内嵌审批卡片，如果侧边栏未打开则 fallback 到 Modal。**

- 审批请求到达时，先尝试找到 `AssistantView` 的 panel 实例
- 如果找到，在消息流中插入 `role: "approval"` 的 ChatMessage
- 卡片显示命令/文件变更详情，用户点击 accept/decline
- 决策后卡片就地折叠，保留历史记录
- 如果侧边栏未打开，主动激活视图并等待 300ms，仍失败则弹出独立 Modal

## 备选方案

- **纯 Modal**：全部弹窗。简单但打断用户工作流，多个审批时体验差
- **纯内嵌**：全部追加到消息流。需要侧边栏始终打开，初次加载时可能延迟

## 后果

- 审批不被中断，用户可以在查看消息流的同时决策
- 审批历史归档到消息流，可追溯、可跨 session 持久化
- 侧边栏未打开时自动激活，有一定延迟（300ms）
- 需要维护 `approvalArchive` 来跨 session 恢复审批历史
