# Architecture Decision Records (ADR)

本目录记录了 AI Whispers 的关键架构决策。

## 格式
每个 ADR 包含：
- **标题**：决策名称
- **状态**：提议 / 已接受 / 已废弃 / 已超期
- **日期**：决策日期
- **背景**：为什么需要这个决策
- **方案**：选择了什么方案
- **备选方案**：考虑过的其他方案
- **后果**：这个决策带来的影响
